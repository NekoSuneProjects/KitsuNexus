# Community Booster migration

Community Booster now uses **kitsunexus-server**, the same server used for
Cloud Sync pairing. The earlier LinkUp device grant proposal is superseded for
Community Booster. Existing LinkUp features unrelated to booster rewards are
unaffected.

See [Community Booster](community-booster.md) for the current setup, server API,
Discord verification rules and desktop behaviour.
